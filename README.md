# 毛选精读

把《毛泽东选集》四卷中的三十七篇核心篇目，逐篇做成**原文与解读并列**的读本。

**站点**：https://huuduch517-dev.github.io/maoxuan-jingdu/

---

## 这个站的职能是训练，不是讲解

讲解员告诉你这一篇的深意——你懂了这一篇，下一篇还得靠我。所以每篇的页面顺序是刻意的：

```
原文（全文）→ 三个问题（先答）→ 写作现场 → 论证形状设问 → 解读五节 → 我的感悟
```

三个问题必须在读解读之前答；「现实应用」的每个情境也先让你写下自己的第一步，再展开本站的推演作对照。**输入交给 AI，输出你自己来。**

衡量这个站好不好只有一条标准：过一段时间，你在读解读之前自己就读到那一层的次数，是不是变多了。

## 论证形状库

这个项目真正的产出不是解读，是**形状**与**读法**——它们换一本书、换一场争论还用得上。目前三种形状：

| 形状 | 动作 |
|---|---|
| **抢前提** | 不驳对方的原则，改判对方的行为不符合那条原则 |
| **改事实基础** | 承认对方的判断在旧条件下成立，论证条件已经变了 |
| **加一层，不拆原路** | 对方的做法效率上确有道理，拆不掉，于是在它上面叠一层责任 |

外加七条读法。每条都挂了本站实例，**没有实例的不许进库**。

## 可信度四级

| 级 | 含义 | 页面标记 |
|---|---|---|
| 原文 | 《毛选》正文，逐字核过 | 实线左栏 |
| 题解注释 | 原书题解与篇末注释 | 实线左栏 |
| 学界看法 | 存在不同看法，如实呈现分歧 | 中性框 |
| 本站判断 | 本站的推断、观察、存疑 | **虚线框**——最该被质疑的部分 |

站内另有一页**存疑索引**，汇总全部「本站判断／存疑」。那是诚实度仪表盘，也是人工核对的工作清单。

## 怎么做的

每篇走三轮，分开执行、不合并：

1. **史实考证** → `research/<slug>.md`，只查不写，每条标注来源等级（原文／推断／存疑）
2. **解读写作** → `docs/篇目/<slug>.md`，六节结构，不得引入考证笔记之外的新史实
3. **对抗性质检** → 脚本逐字核引文、数字回原文数过、否定性断言穷尽复核

规则全部写在 [CLAUDE.md](CLAUDE.md) 里，进度与每轮教训在 [PROGRESS.md](PROGRESS.md)。

## 目录

```
CLAUDE.md          项目宪法（写作立场、三条红线、单篇结构规范）
PROGRESS.md        进度台账 + 每轮备忘
prompts/           六个工作提示词
data/
  themes.yaml      主题词表
  shapes.yaml      论证形状库 + 读法库
docs/篇目/          各篇解读（Markdown，六节结构）
research/          史实考证笔记 + 质检记录
site/
  build.py         原文抽取（PDF → 分节）+ Markdown 渲染
  render.py        页面输出
  qc.py            引文逐字核对与自检
  serve.py         本地预览（带 charset，别用 http.server）
  pages/           构建产物
```

## 本地运行

原文底本（《毛泽东选集》1–4 卷 PDF，人民出版社 1991 年第二版）**不在仓库里**，需自备并放在 `sources/毛选1-4卷.pdf`。

```bash
python site/render.py pages   # 构建到 site/pages/
python site/serve.py          # http://localhost:8766
```

加一篇新文章：跑完三轮产出 `docs/篇目/<slug>.md`，在 `site/build.py` 的 `ART` 里加一行，重跑 `render.py`。原文、存疑索引、金句库、形状库、进度数字全部自动更新。

## 批注

页面上每一节、每一段原文都能写批注。在 claude.ai 的 Artifact 版本里存在服务端；在 GitHub Pages 上存在**本机浏览器的 localStorage** 里——换设备看不到，用「我的感悟」一节底部的「导出 / 导入」带走。
